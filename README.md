
# Adorable Clinic — Static HTML Redesign

A premium, framework-free redesign built with plain HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` directly, or run a tiny local server:

```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Files
- `index.html` — homepage
- `about.html` — clinic story
- `skin.html` — skin treatments
- `hair.html` — hair treatments
- `laser.html` — laser services
- `anti-aging.html` — age-refining care
- `dermatology.html` — clinical dermatology
- `contact.html` — locations/contact
- `appointment.html` — WhatsApp appointment flow
- `privacy.html`, `terms.html`, `404.html`
- `assets/css/style.css`
- `assets/js/main.js`
- `assets/images/*`

## Important before production
1. Verify all business details, hours, addresses, phone numbers and treatment names with the clinic.
2. Replace the concept Privacy/Terms pages with legally approved versions.
3. If you want form submissions stored in a database or email inbox, add a real backend/form service.
4. Review all medical claims with a qualified clinician and local advertising/compliance requirements.
5. Stock images are illustrative; replace them with the clinic's own photography when available.

## Design direction
Deep forest green + warm ivory, editorial serif headings, high-radius image frames, filterable treatments, modern responsive cards, sticky navigation, FAQ accordions, testimonial slider, WhatsApp booking and floating contact actions.
